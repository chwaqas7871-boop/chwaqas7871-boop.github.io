How it works: the app saves every game launch on the device and site where it is opened. This panel reads the same saved data, so open the admin file from the same website as the app. To collect plays from all of your players, put a small server behind the app (set TRACK_URL in the app) and use Sync. The admin code in this file is only a basic lock because it is visible in the page source. A real launch needs server-side login. Earnings shown are estimates: plays multiplied by your rate. Withdrawals: this panel does not send real money. It records each request. You send the amount from your Easypaisa app or business account, then tap Mark paid and enter the transaction ID. Real income only exists if someone pays you, for example through ads, player payments or sponsors, so the rate is a number you decide. Ads: ad earnings here are estimates from the eCPM values you enter (rupees per 1,000 views). Your real ad income is shown in your ad network dashboard (for example Google AdSense), which usually pays to a bank account.
